# Tests and statistics

Delay/exit-IP and speed tests have distinct toolbar, Stash, row and context-menu
actions. Re-test in place; subsets retain others' prior results. Block is not
probed. Settings provide editable preset lists for delay, exit-IP and speed URLs.
Optional UDP testing runs with delay and shows green/struck-through UDP only
when performed. A successful HTTP test proves neither UDP nor bandwidth; UDP
probes do not certify every packet size/app. Speed tests consume bandwidth.

Policy speed tests use the current winner. Health delay display uses minimum
for latency/load strategies and average for random/round-robin. Missing data is
not zero latency. Chains test the assembled path. Inspect Direct's interface
rather than assuming it bypasses every other VPN.

## Traffic

Toolbar rates sit beside Show statistics. The window shows totals/history,
Traffic sources and Outbounds. Headers sort; sorting/units are remembered.
Composite accounting follows compiled executable members; cards are not each
independent network interfaces.

Pause holds display while collection continues. Reset counters resets app
accounting, not Windows counters or provider quotas. History uses counter deltas
over measured intervals. Report bogus spikes with times/diagnostics. A filter's
[Traffic log](traffic-rules.md), not aggregate totals, explains rule selection.
